# Веб-клиент — документация

Документы, нужные только веб-клиенту. Общие для всех приложений (ADR, глоссарий,
бэклог) — в корневой [`docs/`](../../../docs/). Контракт с api —
[ADR-002](../../../docs/ADR/ADR-002-openapi-contract.md).

Типы api: <откуда берутся — сгенерированы из спецификации или написаны по ней; где
лежат; какой командой обновляются после изменения контракта>.

## Оглавление

- [Design](Design.md) — шаблон: дизайн-токены, состояния, тексты и правила интерфейса по страницам.

### [ADR](../../../docs/ADR/README.md)

ADR обязывают веб-клиент так же, как api: словарь интерфейса, визуальное направление,
локализация, лимиты и цены, которые показываются пользователю.
