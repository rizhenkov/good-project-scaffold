# Бэклог

Пока нет трекера, здесь лежит всё, что решено не делать сейчас, но нельзя потерять.
Одна строка на пункт: что сделать, откуда взялось, когда записано. Сделанное удаляется,
а не зачёркивается: история в git. Порядок внутри раздела — примерный приоритет.

Сюда не кладутся планы задач (они — черновики рядом с работой) и решения (они — в
[ADR](ADR/README.md)). Когда задача, ревью или ADR откладывает что-то («позже»,
«отдельным ADR», «когда появится X»), здесь появляется строка.

Формат строки:

```markdown
- Что сделать, в одном-двух предложениях. (Источник: ADR-NNN п. N / ревью / задача, YYYY-MM-DD)
```
